# ai.myheartand.me

《AI 百科全书》（The AI Encyclopedia）App 的落地页（GitHub Pages，仓库 TeancumTian/aibook-site）。`/` 是中文，`/en/` 是英文，打开时按系统语言自动跳，顶栏可以手动切。

这里的文件由 App 仓库里的 `tools/landing.py` 生成：目录、数字和免费边界都从 App 的内容和代码里读，
图片从 App 的插画、图标和商店截图压缩而来。改页面请改生成脚本，重新生成后在这里提交推送；不要直接手改 `index.html`。

App 上架前脚本顶部是 `LIVE = False`，按钮显示「即将上架 App Store」；上架后改成 `True` 重新生成，按钮就链到 App Store。

支持页、隐私政策、使用条款在 [aibook-support](https://github.com/TeancumTian/aibook-support)（https://teancum.me/aibook-support/）。
