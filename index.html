第 32 章 · 从零理解 TransformerChapter 32

32.3手算：3 个位置的因果注意力By hand: causal attention over 3 positions

q = k = (1, 2, 3)，值 (10, 20, 30)，因果掩码下三个位置的输出是 10、18.81、29.48。

with q = k = (1, 2, 3) and values (10, 20, 30), the three outputs under a causal mask are 10, 18.81 and 29.48.

一维、不需要缩放（√1 = 1）：

One dimension, no scaling needed (√1 = 1):

  • 位置 1 只能看自己：权重 [1]，输出 10；
  • 位置 2：分数 2×1 = 2、2×2 = 4，softmax → 0.119、0.881，输出 0.119×10 + 0.881×20 = 18.81；
  • 位置 3：分数 3、6、9，softmax → 0.002、0.047、0.950，输出约 29.48。
  • position 1 sees only itself: weight [1], output 10;
  • position 2: scores 2×1 = 2, 2×2 = 4, softmax → 0.119, 0.881, output 0.119×10 + 0.881×20 = 18.81;
  • position 3: scores 3, 6, 9, softmax → 0.002, 0.047, 0.950, output about 29.48.

本章的互动实验 · 手算因果注意力
用书中 3 个位置的例子一步步算：分数、因果掩码、逐行 softmax、加权求和，得到 10、18.81、29.48；再改数值、关掉掩码。

常见问题FAQ

需要什么设备？

iPhone 或 iPad，系统需要 iOS / iPadOS 18 或更新版本。「用大白话解释」用的是设备上的 Apple 智能模型，需要 iOS 26 和支持 Apple 智能的设备；其他功能都不受影响。

界面和正文能换语言吗？

能。「我的 → 设置 → 语言」里，界面语言可以选中文或 English，阅读语言可以选中文、English 或中英对照。读的时候也能在阅读器工具栏里随时切换。

没学过编程，能读吗？

能。第 1 篇不用写代码，第 2 篇讲怎样用 AI 做研究、核查事实、处理文档和表格这些真实任务；第 3 篇「数学、编程与数据基础」再从第 13 章「从零开始写 Python」讲起。书里有 4 条阅读路线和一个 5 题的先修诊断，帮你找到从哪一章开始。

要联网、要注册吗？

都不用。全部内容装在 App 里，离线可读，没有广告。阅读进度、笔记和练习记录只保存在你的设备上，可以在「我的 → 设置 → 数据」里导出；我们不收集任何数据。

AI 变化这么快，书里的内容会过时吗？

正文讲的是原理和判断方法。价格、模型名、平台参数这类几个月就会变的信息，集中放在附录 A「快变信息（带日期）」，每条都写了核查日期。

换了手机，买过的完整版还在吗？

在。打开「我的 → 设置 → 完整版 → 恢复购买」，用当初购买的 Apple 账户登录 App Store 即可，不会重复扣费。家人共享里的家庭成员也能用。
